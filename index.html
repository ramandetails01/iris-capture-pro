Device setup checklist

  1. Connect the MIS100V2 scanner directly to a USB port on your Windows PC.
  2. Confirm the official Mantra MIS100V2 driver is installed.
  3. Confirm the Mantra MIS100V2 RD Service is installed and running.
  4. Use only the capture workflow supplied by your authorised Aadhaar AUA/KUA or approved service provider.

RD Service status

This GitHub Pages site cannot directly inspect Windows services or verify a local RD Service. Use Windows Services to check it.

  1. Press Win + R, type services.msc, and press Enter.
  2. Find the Mantra MIS100V2 RD Service entry.
  3. Check that its status is Running. If stopped, use Start (if available).
